## Text Formatting

### Headers

Allow you to divide up the different sections of your document. The headers can be big or small depending on the section you are trying to call attention to. Using the `#` is the way to denote that you want a header.

Sample;

```markdown
# Hello World

## Smaller Hello World

### Even Smaller Hello World
```

Sample Output;

# Hello World

## Smaller Hello World

### Even Smaller Hello World

Typically, the headers can be used up to 6 times in a row for the smallest size.

### Italics

Are used in writing to call attention to tone, titles for works, scientific names and more. They're a great way to _convey_ tone in written form. Using the `*` around the text you want to italicize is how it is done.

Sample;

```markdown
Tone is _especially_ hard to convey in text, so using it is important to capture the scenes correctly. While not my favorite book, _The Catcher in the Rye_ does this well.
```

Sample Output;

Tone is _especially_ hard to convey in text, so using it is important to capture the scenes correctly. While not my favorite book, _The Catcher in the Rye_ does this well.
